# Literature review

A review synthesises; it does not list. Each paragraph makes a point and cites several works for it.

## Method: synthesis matrix

1. Build a matrix from the supplied or searched papers only: rows are works, columns are
   question, context and sample, method, key finding, limitation, theme.
2. Group the rows into 3–6 themes (constructs, debates, methods or chronology when the field moved).
3. Write one subsection per theme: the claim, the agreeing evidence, the disagreeing evidence, the
   reason for the disagreement (method, context, period), and what remains open.
4. Close with the gap statement and the framework the study uses.

Show the matrix to the user as a table when they asked for a review of given papers; it lets them
check every claim against a source.

## Paragraph pattern

Topic sentence (the point) → evidence from 2–4 works compared → evaluation → link to the next point
or to this study. Avoid "Smith (2019) found… Jones (2020) found… Lee (2021) found…".

## Gap statement

"Although [what is established, cited], [what remains unknown] in [context/population/method]
[cited evidence of absence or limitation]. This study therefore [aim]." Types: contextual (not
studied in Sri Lanka), population, methodological (only cross-sectional), theoretical, conflicting
findings, outdated evidence. Absence of evidence needs a described search, not memory.

## Lengths

Thesis chapter: 20–30% of the thesis. Paper: 800–2,000 words or merged into the introduction.
Standalone review article: 6,000–10,000 words, with the search protocol (databases, strings, dates,
inclusion criteria; PRISMA for a systematic review).

## Without sources

If the user supplied no papers and no search was run, write the structure and the argument with
`[citation needed: ...]` markers, and offer to search. Never fill citations from memory.

## Common reviewer complaints

- Annotated bibliography instead of synthesis; no critical evaluation.
- Old sources only; key recent work missing; over-reliance on one author.
- Gap claimed without evidence; framework appears from nowhere.
