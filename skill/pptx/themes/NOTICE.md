# Theme sources

The five theme masters are LibreOffice Impress templates from
https://github.com/LibreOffice/core (`extras/source/templates/presnt`, commit
5c6e7587dfd8), converted to .pptx and cleaned: rescaled to 13.333 × 7.5 in, layouts
renamed, placeholders named, Nikosh set for Bangla. They are covered by the LibreOffice
repository licence (MPL-2.0); several were contributed under CC0.

| Theme | Original authors |
|---|---|
| Candy | Ermin D. Alita and others |
| Growing_Liberty | Budi Aryo |
| Freshes | Risyad Rais |
| Yellow_Idea | Dwi Alita |
| Grey_Elegant | Ahmad Bayhaqi Saputra |

Rebuild them with `docs/slide-templates/tools/clean.py` and `config.json`.
