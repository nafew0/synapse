# Leave and duty requests

Source: Establishments Code of the University Grants Commission and Higher Educational Institutions,
Chapter X (https://www.ugc.ac.lk//downloads/ecode/Chapter%20X.pdf), applying to Sri Lankan
universities. Read the chapter for a case not covered here; quote the section only if you have read
it. For another country or body, follow what the user gives.

- Leave is applied for on the prescribed form (1.7). If the user has the form, use `form-filling`.
- Routing: Head of Department, then Dean, then Vice-Chancellor (1.7.1). Put these in `through`,
  or in `recommenders` for sign-off lines.
- Conference leave: section 39.1. Sabbatical: section 37.
- Leave abroad attaches the approval form, the invitation or award letter, a statement of past
  overseas leave and the total cost with the source of funds (1.10.1). Set `leave_type: abroad` and
  the gate checks that `enclosures` names each one.
- The Peradeniya overseas leave form also asks who covers the work, signed by the Head
  (https://agri.pdn.ac.lk/front_img/1661708190Overseas_Leave_Application_Form.pdf). Say who covers
  it in the body when the user tells you.

Never state a leave balance, an entitlement or a day count the user did not give. For a question on
entitlement, point to the chapter and the section.
