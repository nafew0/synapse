What Synapse is

Synapse is BdREN's AI workspace: one chat window in front of several frontier language models and a set of purpose-built agents. Instead of learning a different tool for drafting a letter, cleaning up a spreadsheet, or reformatting a slide deck, you describe the task in plain language and Synapse routes it to whichever model, agent, or file-editing skill is suited to it.

This guide covers the key features of Synapse an everyday user including chats, attaching files, model-agent selection and so on. Upcoming features guide will be added soon.

The Office Assistant

The Office Assistant is a master agent specially ooptimized to handle most of the day to day office works including editing files, documents and so on. You simply ask question or give it file with instruction it will handle the rest of the work for you. Currently, the Office Assistant is equipped with following capabilies:/p>

  • Compose professional emails, reports, and document drafts
  • Edit, refine, and update DOCX, XLSX, and PPTX files
  • Create polished documents and presentation decks from scratch
  • Analyze spreadsheets, perform calculations, and update data
  • Generate custom images and visual content from text prompts
Requesting Sick Leave via Email

A real exchange: three short questions (recipient, duration, tone), then Transferred to Mail Assistant and a finished draft — no separate agent to find or select.

The same pattern applies to spreadsheets, presentations, and documents: describe what you need, answer whatever it asks, and the right specialist takes over.

03

Attaching files

The paperclip icon under the message box now opens just two choices — Synapse figures out the rest automatically based on what the file is and what the current assistant can do with it.

  1. Upload Image: Send a photo or screenshot straight to the model as visual context.
  2. Upload file: Hand over any document (PDF, Word, Excel, PowerPoint, text) and Synapse automatically reads, searches, or prepares it for editing — whichever fits both the file and the assistant you're talking to.

While a file uploads, its chip shows a short status — Uploading…, Reading…, Recognising text…, Indexing… — then how the model will use it: Read in full, Searchable, Ready to edit, Image, or Transcribed.

Only the Office Assistant can edit a file and hand back a changed copy. ChatGPT, Claude, and GLM 5.2 can read and search an attached file and answer questions about it, but cannot edit it — ask one of those to change a document and it will tell you to switch to the Office Assistant instead.

Files you attach are also saved to My Files (icon rail → paperclip), so you can reuse them in a later chat without re-uploading.

04

Prompts

The Prompts panel is a personal library of reusable message templates — useful for anything you phrase the same way often, like a weekly status update or a standard meeting summary format.

Type / in the message box to bring up your saved prompts without leaving the keyboard, or open the panel from the rail to create a new one.

My Files

Every file you've ever attached lives in My Files (paperclip icon), searchable and sorted by date — handy for re-attaching something without hunting through old chats.

Reporting an issue

When something goes wrong, Synapse shows a short message with a Report an issue button. One click sends our team the exact error behind it, so we can find the cause and fix it right away.

  1. Click Report an issue on the error.
  2. Say in a sentence what you were trying to do.
  3. Click Send report.

The report carries the technical details for you: the real error, a reference code, the page, and your browser. It never includes your other chats or files.

Have a screenshot? Reply to our email about your report and attach it. If a report can't be sent, email info@bdren.ai.
